# Markman Tomashkin – גרסה אחרונה (v5)

6 קבצים עצמאיים, נבנו מחדש מהגרסה העדכנית (קאבר חדש, סליידרים מתוקנים).

## העלאה ל-GitHub Pages
1. מחקו מהריפו את **כל** הקבצים הקודמים (כולל תיקיות assets / support.js ישנים).
2. העלו את 6 קבצי ה-HTML לשורש הריפו (לא לתוך תיקייה).
3. Settings → Pages → main / (root).
4. חכו 2–3 דקות, ואז פתחו עם רענון קשיח (Ctrl+Shift+R) או בחלון גלישה בסתר — אחרת הדפדפן עלול להציג גרסה ישנה מהקאש.
